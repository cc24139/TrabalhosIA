## 📝 Descrição
O trabalho visa a criação de uma IA em Python (3.14) que possa jogar o jogo de tabuleiro de dois jogadores Othello contra outra IA. Para isso, o algoritmo mini-max será usado como base, com a adição de outras estratégias, como o alpha-beta pruning, para melhorar o seu desempenho.
Um relatório do trabalho será feito, introduzindo o projeto, a modelagem do problema, os algoritmos implementados, os resultados obtidos e as conclusões tiradas a partir do trabalho.

##  🚀 Como rodar o projeto
## 📋 Pré-requisitos
    Python 3.14 instalado
## 📥 1. Clonar o repositório
```
git clone https://github.com/taquaras/ti326m-trabalho1-equipe3.git
```
## 🐍 2. Criar o ambiente virtual
```
python -m venv venv
```
## ⚙️ 3. Ativar o ambiente virtual

Windows:
```
venv\Scripts\activate
```
Linux/Mac:
```
source venv/bin/activate
```

