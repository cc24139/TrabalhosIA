## 📝 Descrição
Esse trabalho tem como objetivo implementar e comparar duas meta-heurísticas, o Iterated Local Search (ILS) e o Biased Random-Key Genetic Algorithm (BRKGA), para resolver o problema do Caixeiro Viajante com Coleta e Entrega. O projeto envolve a implementação de ambas as heurísticas, a execução de testes em instâncias específicas do problema e a análise dos resultados obtidos.

## 🚀 Como rodar o programa
1. Certifique-se de ter o Python 3 instalado em seu sistema.
2. Clone o repositório do projeto para sua máquina local.
3. Crie um ambiente virtual para o projeto (opcional, mas recomendado):
   ```
   python -m venv venv
   ```
4. Navegue até o diretório do projeto e instale as dependências necessárias usando o comando:
   ```
   pip install -r requirements.txt
   ```
5. Execute o programa principal:
   ```
    python main.py
    ```
